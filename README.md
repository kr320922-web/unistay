
# UniStay – Hostel Management System

UniStay is a web-based Hostel Management System developed using PHP, MySQL, HTML, CSS, and JavaScript.

## Features

- Student Dashboard
- Admin and Warden Management
- Room Allocation
- Hostel Fee Management
- Complaint Management
- Leave Requests
- Mess Menu
- Laundry Services
- Notices and Events
- Parcel Management
- SOS / Emergency Support

## Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Local Server: XAMPP

## Local Setup

1. Install XAMPP.
2. Copy the UniStay project folder into `C:\xampp\htdocs\`.
3. Start Apache and MySQL.
4. Create a MySQL database named `unistay_db`.
5. Import the project's database schema if available.
6. Copy `db.example.php` to `db.php`.
7. Update `db.php` with your local database credentials.
8. Open `http://localhost/UniStay/` in your browser.

## Database Configuration

The `db.php` file is excluded from GitHub for security.

Use `db.example.php` as a template.

## Note

GitHub hosts the source code. A PHP and MySQL hosting provider is required to run the application online.
